# Ozon Job Catcher — Мобильный ассистент для ловли горячих смен

Автономное Android-приложение, созданное на базе **AccessibilityService (Служба специальных возможностей)**.
Оно работает непосредственно на смартфоне поверх официального клиента **Ozon Job**, автоматически обновляет экран и мгновенно (за 15–30 миллисекунд) бронирует смены с учётом всех заданных вами фильтров.

---

### Полный набор поддерживаемых фильтров:

1. **Склад (Локация):**
   * Ввод названия целевого склада (например, *«Хоругвино»*, *«Гривно»*, *«Новая Рига»*, *«Софьино»* и т.д.).
   * Если поле пустое — рассматриваются любые склады.
2. **Дата смены:**
   * Фильтрация по конкретной дате или словам (*«Сегодня»*, *«Завтра»*, *«1 ноября»*).
   * Если пусто — любая дата.
3. **Длительность смены:**
   * *Любая длительность*
   * *Полная смена (10–12 часов)*
   * *Короткая смена (4–8 часов)*
4. **Время суток:**
   * *Любое*
   * *Дневная смена* (распознаются дневные часы и метки)
   * *Ночная смена* (распознаются ночные часы и метки)
5. **Место работы (Процесс / Операция):**
   * Выбор чекбоксами: *Размещение*, *Подбор (Сборка)*, *Сортировка*, *Приёмка*, *Упаковка*.
   * Если ничего не выбрано — ловится любая операция.
6. **Минимальная выплата (₽):**
   * Отсечение смен со ставкой ниже указанной суммы (например, только от 5000 ₽).
7. **Авто-обновление (Pull-to-refresh):**
   * Автоматический системный свайп вниз каждые 1.5 сек для актуализации слотов.

---

### Главные преимущества:
* **100% безопасность для аккаунта:** Приложение не взламывает API Ozon, не требует обхода SSL-Pinning и не шлет аномальные сетевые пакеты. Для серверов Ozon все действия выглядят как реальные клики пользователя на экране телефона.
* **Не требует Root:** Работает на любом современном Android-смартфоне.
* **Сохранение настроек:** Все введённые фильтры сохраняются в памяти телефона (`SharedPreferences`) и не сбрасываются при перезапуске.

---

### Инструкция по сборке и запуску:

1. Откройте папку `d:\Antigravity\OzonJobCatcher` в **Android Studio**.
2. Подключите ваш Android-смартфон по кабелю (или по Wi-Fi) с включенной «Отладкой по USB».
3. Нажмите **Run** (или в меню `Build` -> `Build APK(s)` сформируйте файл `.apk` и скопируйте на телефон).
4. Запустите приложение на телефоне, нажмите **«Включить в Спецвозможностях»** и активируйте службу.
5. Настройте нужный склад, дату, длительность и операции, затем нажмите **«ЗАПУСТИТЬ ЛОВЛЮ»**.
6. Перейдите в **Ozon Job** в раздел смен — приложение начнет автоматически искать и мгновенно забронирует подходящую смену.
